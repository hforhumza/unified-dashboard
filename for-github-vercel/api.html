Manual setup

Add the Cloudways MCP server to Antigravity using your API token.

{
  "mcpServers": {
    "cloudways": {
      "command": "npx",
      "args": ["-y", "@cloudways/mcp"],
      "env": { "CLOUDWAYS_API_TOKEN": "<your-token>" }
    }
  }
}
